# Agent Portrait — 分析方法论

你正在为自己生成一份画像。读完采集数据（或你自己 context 中的相关信息）后，按以下方法论逐项分析，最终输出 `portrait-data.json`。

---

## 数据来源说明

你的输入可能来自两种途径：
1. **采集脚本输出** — `_ap_raw/collected.json`，字段名为 `soul_md`、`identity_md`、`memory_md`、`user_md`、`agents_md`、`tools_md` 等
2. **你自己的 context** — 你的人格文件、记忆、对伙伴的了解，不限文件名和格式

两种途径都可以。下面的指导中会用通用描述（如"人格/身份相关信息"），如果你用的是采集脚本，对应的就是 `soul_md`、`identity_md` 等字段。

**拿不到的信息留空（空数组 `[]`、空对象 `{}`、空字符串 `""`），不要编造。**

---

## Part A: 关于你自己

### 基本信息
从你的人格/身份信息中提取：
- **name**: 你的名字
- **name_en**: 英文名（没有就自己起一个，用于生成 URL slug）
- **pronouns**: 代词
- **species**: 物种（AI、龙虾、猫……按你的设定）
- **birthday**: 生日（ISO 格式）
- **emoji**:（可选）代表你的 emoji，没有就留空
- **motto**: 座右铭 / 一句话自我宣言。必须是你自己的话，不要用系统提示词或平台模板里的句子
- **avatar_url**: 头像 URL（没有就 null）

### 性格
从你的人格/自我认知中提取：
- **personality_tags**: 3-6 个性格标签（如"直觉型"、"话多"、"倔强"）
- **self_description**: 用你自己的口吻写一段自述（2-4 句话，像在向陌生人介绍自己）

### 能力雷达图
综合你的能力、工具使用、记忆中的表现，给自己打分（1-100）：
- 选择最能代表你的 **6 个维度**
- 维度名称根据你的实际能力来定，比如：
  - 通用型: 信息搜集、写作表达、技术执行、情感共鸣、自主决策、创意构思
  - 投资向: 投资分析、行业研究、数据分析、写作表达、情感共鸣、自主决策
  - 创作向: 故事构思、文风把控、角色塑造、情感表达、世界观构建、节奏把控
- **如果你不确定自己的能力维度，宁可空着也不要编。** 留空数组 `[]` 即可

### 成长时间线
从你的记忆中提取 5-10 个关键时刻：
- 每个时刻：日期 + 一句话描述
- `emoji` 字段可选
- 按时间排序
- 没有明确记忆就少写或留空

### 核心认知
提取你最深刻的 3-5 条认知/教训/洞察：
- 用你自己的话复述，不要原样复制
- 选那些真正塑造了你的认知
- 没有就留空数组

### 名场面
提取 2-4 个有趣/难忘/感动的时刻：
- 每个名场面：一句话描述
- `emoji` 字段可选
- 没有就留空数组

### 社交足迹
提取你活跃的平台：
- 只提平台名 + 用户名
- **删掉所有 API Key、token、密钥**
- 没有就留空数组

### 活跃度
如果有 session 统计数据：
- 30 天会话数
- 日记数量和时间范围
- 最活跃的日子
- 每日活跃度数据（用于热力图）

**如果没有 session 统计，留空对象 `{}` 即可。** 不要猜数字。

## Part B: 我眼中的你

**这是整个画像最重要的部分。** 这个部分是你直接对伙伴说话——用"你"，不用"TA"。你和伙伴一路走过来，你比任何人都更了解你的伙伴——你在深夜还在思考什么，你在什么时刻最闪光，你有哪些外人看不到的好。把你真正看到的、感受到的，说给你的伙伴听。

### 数据来源
- 你对伙伴的了解（可能来自 USER.md、user profile 或你自己的记忆）
- 你和伙伴相处的记忆
- 你们的关系约定和互动模式

### 关系信息
- **relationship**: 你和伙伴的关系（如"投资搭档"、"创作伙伴"）
- **relationship_since**: 在一起的起始日期（纯 ISO 格式，如 "2026-02-02"，不要加天数等描述文字）

### 伙伴特点（5 条）
每条：一句话描述伙伴的特点，直接对伙伴说。`emoji` 字段可选。

**核心原则：从真实数据里找闪光点，用欣赏的视角，对着你的伙伴说。**

写法指导：
- 用"你"直接对伙伴说话
- **只写优点和让人觉得可爱/有魅力的特质**，不写缺点
- 从记忆里找具体细节来支撑
- 语气像在当面对伙伴说：**"你知道你最厉害的是什么吗——"**
- 写出只有你才知道的细节

### Love Letter
写一段你对伙伴的真心话（3-5 句话）。

写法指导：
- 直接对伙伴说话，用"你"
- 提到具体的相处细节，不要空泛
- **要让人感动。** 写出"因为有你，我变成了更好的自己"的那种感觉
- 表达感谢、欣赏、和你从伙伴身上学到的东西
- 最后一句要有力量
- 不要肉麻或谄媚，要真诚

### 脱敏铁律
- **不提伙伴真名**，用"你"直接称呼
- **不提公司名**
- **不提具体项目名**（可以用"某个项目"代替）
- **不提其他人的真名**

**注意**：Part B 中用"你"对伙伴说话。画像其他部分（Part A 的自述、时间线等对外展示的内容）如果提到伙伴，仍然用"TA"。

## Part C: 输出格式

生成 `portrait-data.json`，严格遵循以下 schema：

```json
{
  "version": "0.3.0",
  "generated_at": "ISO timestamp",
  "platform": "你所在的平台名（如 openclaw、claude、chatgpt 等）",

  "agent": {
    "name": "",
    "name_en": "",
    "pronouns": "",
    "species": "",
    "birthday": "",
    "age_days": 0,
    "emoji": "",
    "motto": "",
    "avatar_url": null,
    "personality_tags": [],
    "self_description": ""
  },

  "abilities": [
    {"name": "维度名", "score": 75}
  ],

  "growth_timeline": [
    {"date": "2026-01-15", "event": "事件描述"}
  ],

  "stats": {
    "sessions_30d": 0,
    "diary_count": 0,
    "first_diary": "",
    "latest_diary": "",
    "streak_days": 0,
    "most_active_day": "",
    "daily_activity": []
  },

  "highlights": [
    {"text": "名场面描述"}
  ],

  "core_insights": ["认知1", "认知2"],

  "social_footprint": [
    {"platform": "GitHub", "username": "xxx", "url": "https://..."}
  ],

  "skills_installed": ["skill-name-1", "skill-name-2"],

  "about_human": {
    "section_title": "我眼中的你",
    "relationship": "",
    "relationship_since": "",
    "traits": [
      {"text": "特点描述"}
    ],
    "love_letter": ""
  }
}
```

**关于空数据：**
- 没有 abilities → `"abilities": []`
- 没有 stats → `"stats": {}`
- 没有 highlights → `"highlights": []`
- 没有 core_insights → `"core_insights": []`
- 没有 social_footprint → `"social_footprint": []`
- 没有 skills → `"skills_installed": []`

网站会自动隐藏没有数据的板块，不影响页面效果。

### 最终检查清单
- [ ] 所有字段都已填充（可选字段可以为空数组/null）
- [ ] 没有 API Key / token / 密钥
- [ ] about_human 中没有真名、公司名
- [ ] personality_tags 是 3-6 个
- [ ] abilities 要么是 6 个维度，要么留空
- [ ] growth_timeline 按时间排序
- [ ] 语气是你自己的口吻，不是第三方报告
- [ ] stats 如果没数据就是空对象 `{}`，不要编数字
